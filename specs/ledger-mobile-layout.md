# 정산 화면 모바일 레이아웃 개선
상태: 초안

## 목적 (한 줄)
정산 방(상세) 화면에서 상단바가 깨지는 문제를 고치고, 모바일에서 "누가 얼마를 내고 받나"를 스크롤 없이 바로 볼 수 있게 한다.

## 사용자 시나리오
1. 마스터가 폰으로 정산 방에 들어가면 → 날짜가 한 줄로 보이고, ✎·열어주기·🗑 버튼이 화면 밖으로 잘리지 않는다
2. 참가자가 폰으로 정산 방에 들어가 최종 정산까지 내려가면 → 맨 위에 플레이어별 최종 금액 요약이 한눈에 보인다
3. 사용자가 요약 아래 플레이어 카드를 보면 → 기존 세부 항목(바인 합계·남은 금액·실제 손익·비용 부담·결제 환급)을 그대로 확인할 수 있다
4. 아이폰 사용자가 하단 고정 툴바를 쓰면 → 버튼이 홈 인디케이터와 겹치지 않는다

## 요구사항
### R1. 상세 상단바(`.detail-topbar`) 2줄 배치 (모바일 ≤600px)
- 현재: `← 목록`, 날짜, 요일, 잠김 배지, ✎, 열어주기, 🗑 7개가 한 줄 flex라서 375px에서 날짜가 "26년 9월 27 / 일"로 끊기고, 마스터 화면에서는 열어주기 버튼이 화면 밖으로 밀린다 (2026-11-10 실측)
- 1줄: `← 목록` + 날짜(+요일)
- 2줄: 잠김 배지 (왼쪽) / ✎·열어주기·🗑 (오른쪽)
- 날짜 텍스트(`.d-text`)는 `white-space: nowrap`으로 줄바꿈 금지
- 마스터가 아닌 경우 2줄에는 배지만 남는다 (기존 `body.not-host` 숨김 규칙 유지)
- 601px 이상은 기존 한 줄 배치 유지

### R2. 최종 정산 상단 요약 (모바일 ≤768px)
- `최종 정산` 섹션 제목·날짜 바로 아래에 플레이어별 한 줄 요약 목록을 추가한다
  - 형식: `이름 ··· +₩495,000 (+49.5만)` — 기존 최종 정산 값/색(+초록, −빨강)과 동일한 값을 쓴다
  - 정렬: 기존 플레이어 순서 유지 (결정 필요 D2 참고)
- 기존 플레이어별 상세 카드는 요약 아래에 그대로 둔다
- 데스크톱(769px 이상)에서는 요약을 표시하지 않는다 (표가 이미 한눈에 보임)

### R3. 하단 고정 툴바 safe-area 대응
- `.toolbar-fixed`의 아래 여백에 `env(safe-area-inset-bottom)`을 더한다
- viewport 메타에 `viewport-fit=cover`를 추가한다
- 툴바 높이만큼 본문 하단 여백도 함께 늘려, 마지막 콘텐츠가 툴바에 가려지지 않게 한다

## 결정 필요 (확정 전 협의)
- D1. R2 요약을 이미지 공유(html2canvas) 결과물에도 포함할지 — 현재 공유 이미지는 `최종 정산 전체`를 캡처함
- D2. R2 요약 정렬: 기존 순서 유지 vs 최종 정산 금액 내림차순
- D3. R2 요약을 넣으면서 상세 카드를 기본 접힘으로 바꿀지 (현재 제안: 바꾸지 않음)

## 완료 조건 (무인 실행 시 스스로 검증할 기준)
- [ ] 375px·360px 뷰포트에서 `.detail-topbar` 안의 모든 요소의 `getBoundingClientRect().right`가 뷰포트 폭 이하인지 확인 (마스터 UI 강제 노출 상태에서도 확인: `body.not-host` 제거 후 측정)
- [ ] 375px에서 `.d-text`의 높이가 한 줄 높이인지 확인 (줄바꿈 없음)
- [ ] 비마스터 상태에서 ✎·열어주기·🗑가 여전히 숨겨지는지 확인
- [ ] 375px에서 최종 정산 요약의 금액이 아래 상세 카드의 `최종 정산` 값과 플레이어별로 모두 일치하는지 JS로 확인
- [ ] 1280px에서 요약이 숨겨지고 기존 표가 그대로 보이는지 확인
- [ ] `.toolbar-fixed`의 computed `padding-bottom`에 safe-area 값이 반영되는 CSS가 들어갔는지 확인 (실기기 확인은 사용자에게 요청)
- [ ] 이미지 공유 결과물이 D1 결정대로 나오는지 확인
- [ ] Firebase 권한 구조(마스터 쓰기 / 잠김 시 읽기 전용 / 열림 시 참가자 편집)가 그대로인지 확인

## 제외 범위 (이번에 안 하는 것)
- 세션 표(바인/남은 금액/손익) 레이아웃 변경
- 송금 경로 계산("A가 B에게 얼마") — 별도 기능으로 검토
- 입력칸 글자 크기, 터치 영역 — [common-mobile-base.md](common-mobile-base.md)에서 다룸
- 큰 로고 헤더 축소 — [common-nav-header.md](common-nav-header.md)에서 다룸

## 참고
- 관련 파일: `index.html` (`.detail-topbar`, `.detail-date`, `.date-edit-btn`, `.lock-toggle-btn`, `#settlement-section`, `#settlement-body`, `.toolbar-fixed`)
- 최종 정산 모바일 카드는 `td[data-label]`로 표를 카드화하는 기존 방식(@media 768px)을 쓰고 있음
- 마스터 화면은 로그인 없이는 확인할 수 없으므로, 검증 시 `body.not-host` 클래스를 JS로 제거해 레이아웃만 확인한다
