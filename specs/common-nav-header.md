# 공통 상단바 (페이지 간 내비게이션 통일)
상태: 초안

## 목적 (한 줄)
페이지마다 다른 뒤로가기/헤더 모양을 하나의 얇은 상단바로 통일하고, 모바일에서 큰 로고 헤더가 차지하던 공간을 콘텐츠에 돌려준다.

## 사용자 시나리오
1. 사용자가 어느 기능 페이지에 들어가도 → 같은 위치·같은 모양의 상단바에서 홈으로 돌아갈 수 있다
2. 사용자가 정산 방에 들어가면 → 큰 로고 대신 얇은 상단바가 보여, 첫 화면에 플레이어/세션 내용이 더 많이 보인다
3. 사용자가 홈에 들어가면 → 기존처럼 로고(히어로)가 보인다

## 요구사항
- 현재 상태 (2026-11-10 실측)
  - 홈·게임 기록·정산 방(`index.html`): 큰 로고 히어로(375px에서 약 140px)가 모든 화면에 반복 + 화면별 `← 홈`/`← 목록` 버튼
  - Push/Fold·Hand Ranking: `‹ Holdem Mates` 텍스트 링크 + 별도 베이지 팔레트
  - 딜 계산기: `← 홈` 버튼 + 페이지 제목
- 홈 외 모든 화면에 공통 상단바를 둔다
  - 구성: 왼쪽 뒤로가기(`←` + 대상 이름: `홈` 또는 `목록`), 가운데 또는 왼쪽 정렬 페이지 제목, 오른쪽 유저영역(마스터/로그인 — `index.html`에만)
  - 높이 약 48px, 모바일 상단에 sticky 고정 여부는 결정 필요(D2)
- 홈 화면은 기존 히어로 유지
- 단일 HTML 파일 구조 유지: 공용 JS/CSS 파일로 분리하지 않고 각 파일에 같은 마크업·CSS를 복제한다 (결정 필요 D3)

## 결정 필요 (확정 전 협의)
- D1. 백로그 "Push/Fold 차트 팔레트를 홈 화면과 통일"을 이 스펙에 포함할지 — 제안: 상단바만 이 스펙, 팔레트는 별도
- D2. 상단바 sticky 고정 여부 — 제안: 정산 방만 고정하지 않음(하단 툴바와 합쳐 화면이 좁아짐), 나머지는 고정
- D3. 상단바 코드를 각 HTML에 복제할지, 공용 파일로 뺄지 — CLAUDE.md상 단일 파일 구조 유지가 원칙이므로 제안: 복제

## 완료 조건 (무인 실행 시 스스로 검증할 기준)
- [ ] 홈을 제외한 모든 화면(게임 기록, 정산 방, Push/Fold, Hand Ranking, 딜 계산기)에 같은 클래스 구조의 상단바가 있는지 확인
- [ ] 각 화면의 뒤로가기가 올바른 곳(정산 방 → 목록, 나머지 → 홈)으로 이동하는지 확인
- [ ] 375px에서 상단바 높이가 56px 이하인지 확인
- [ ] 375px 정산 방에서 첫 화면에 보이는 콘텐츠 시작 위치가 변경 전보다 위로 올라왔는지 확인
- [ ] 홈 화면 히어로와 우측 상단 유저영역(마스터/로그인)이 기존과 같이 동작하는지 확인
- [ ] 601~767px 구간에서 유저영역이 잘리지 않는지 확인 (PR #3에서 고친 문제 재발 방지)
