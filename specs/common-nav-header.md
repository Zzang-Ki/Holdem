# 공통 상단바 (페이지 간 내비게이션 통일)
상태: 확정 (2026-11-10)

## 목적 (한 줄)
페이지마다 다른 뒤로가기/헤더 모양을 하나의 얇은 상단바로 통일하고, 모바일에서 큰 로고 헤더가 차지하던 공간을 콘텐츠에 돌려준다.

## 사용자 시나리오
1. 사용자가 어느 기능 페이지에 들어가도 → 같은 위치·같은 모양의 상단바 왼쪽 버튼으로 이전 화면(홈/목록)에 돌아갈 수 있다
2. 사용자가 정산 방에 들어가면 → 큰 로고 대신 얇은 상단바가 보여, 첫 화면에 플레이어/세션 내용이 더 많이 보인다
3. 사용자가 홈에 들어가면 → 기존처럼 큰 로고(히어로)가 보인다
4. 마스터/로그인 유저영역은 홈·게임 기록·정산 방에서 기존처럼 오른쪽 위에 보인다

## 요구사항
- 현재 상태 (2026-11-10 실측)
  - 홈·게임 기록·정산 방(`index.html`): 큰 로고 히어로(375px에서 약 140px)가 모든 화면에 반복 + 화면별 `← 홈`/`← 목록` 버튼 박스
  - Push/Fold·Hand Ranking: `‹ Holdem Mates` 텍스트 링크 + 별도 베이지 팔레트
  - 딜 계산기: `← 홈` 버튼 + 페이지 제목
- 홈 외 모든 화면에 공통 상단바를 둔다
  - 구성: **왼쪽** 뒤로가기 버튼(`← 홈` 또는 `← 목록`) / **가운데** 작은 브랜드(스페이드 + HOLDEM MATES 워드마크) / **오른쪽** 유저영역(`index.html`에만, 나머지는 빈 칸)
  - 페이지 제목(Push/Fold Chart, Hand Ranking, 딜 계산기, 게임 기록)은 상단바가 아니라 기존처럼 본문에 둔다 (제목 중복 방지)
  - 높이 약 48px, 화면 전체 폭
- `index.html`
  - 홈 화면: 기존 히어로 그대로
  - 게임 기록·정산 방 화면: 히어로가 공통 상단바 모양으로 바뀐다 (`#host-bar`는 같은 요소를 그대로 사용)
  - 게임 기록 화면의 `← 홈` 버튼 박스, 정산 방 상단바의 `← 목록` 버튼은 공통 상단바로 옮긴다 (기존 위치에서 제거)
- `pushfold-chart.html`, `hand-ranking.html`: `‹ Holdem Mates` 링크를 공통 상단바로 교체 (색은 각 페이지 팔레트 변수 사용)
- `deal-calculator.html`: `.topbar`의 `← 홈` 버튼을 공통 상단바로 옮기고, `딜 계산기` 제목은 본문에 남긴다

## 결정 사항 (2026-11-10 확정 — 사용자가 제안안 일괄 채택)
- D1. 페이지 팔레트 통일은 **이 스펙에 포함하지 않는다** (백로그 항목 유지)
- D2. 상단바는 **어느 화면에서도 sticky 고정하지 않는다** — 초안 제안(정산 방만 비고정)에서 단순화: Push/Fold는 첫 화면에 차트를 보여야 하고, 정산 방은 하단 툴바가 이미 고정이라 모든 화면을 비고정으로 통일
- D3. 단일 HTML 구조 원칙에 따라 **각 파일에 마크업·CSS를 복제**한다 (공용 파일 분리 안 함)

## 완료 조건 (무인 실행 시 스스로 검증할 기준)

- [ ] 각 화면의 뒤로가기가 올바른 곳(정산 방 → 목록, 나머지 → 홈)으로 이동하는지 확인
