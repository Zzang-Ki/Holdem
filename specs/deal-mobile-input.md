# 딜 계산기 플레이어 입력칸 모바일 개선
상태: 확정 (2026-11-10)

## 목적 (한 줄)
폰에서 딜 계산기의 보유 칩 입력칸이 좁아 숫자가 잘 안 보이는 문제를 고치고, 각 칸이 무엇인지 알 수 있게 한다.

## 사용자 시나리오
1. 사용자가 폰으로 딜 계산기 플레이어 영역을 보면 → 이름 칸과 칩 칸이 화면 폭을 알맞게 나눠 쓴다 (오른쪽에 빈 공간이 남지 않는다)
2. 사용자가 칩 칸에 `1,250,000` 같은 큰 숫자를 넣으면 → 숫자가 잘리지 않고 다 보인다
3. 사용자가 빈 입력칸을 보면 → 이름 칸에는 `P1`, 칩 칸에는 `보유 칩`처럼 무엇을 넣을지 보인다

## 요구사항
- 현재: 375px에서 이름 칸 175px, 칩 칸 62px이고 오른쪽에 빈 공간이 남음. 칩 칸 placeholder 없음 (2026-11-10 실측)
- 원인 추정: 칩 칸이 `type="text"`라서 이름 칸용 선택자 `.player-row input[type=text]`(`flex: 0 0 78px`, ≤380px에서 `flex-basis: 62px; font-size: 12px`)가 칩 칸에도 적용됨 — 구현 시 확인
- 이름 칸 선택자를 칩 칸과 분리한다 (예: 이름 칸 전용 클래스)
- 모바일에서 이름 칸 : 칩 칸 = 약 4 : 6 비율, 칩 칸이 남은 폭을 모두 쓴다
- 칩 칸에 placeholder `보유 칩`을 넣는다
- 섹션 라벨 `플레이어 (이름 / 보유 칩)`은 유지

## 완료 조건 (무인 실행 시 스스로 검증할 기준)
- [ ] 375px·360px에서 플레이어 행의 이름 칸 + 칩 칸 + 간격이 행 폭을 채우는지(오른쪽 빈 공간 ≤ 4px) 확인
- [ ] 375px에서 칩 칸 폭이 이름 칸 폭보다 넓은지 확인
- [ ] 칩 칸에 `1250000` 입력 시 표시값 전체가 칸 안에 보이는지(`scrollWidth ≤ clientWidth`) 확인
- [ ] 칩 칸 placeholder가 `보유 칩`인지 확인
- [ ] 간편/정밀 모드, 인원 2~9명에서 행 레이아웃이 깨지지 않는지 확인
- [ ] 같은 입력값으로 변경 전후 계산 결과(분배 금액)가 동일한지 확인
